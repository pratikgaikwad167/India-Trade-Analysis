# India Export-Import Trade Analysis Dashboard
Excel + Power Bl project analyzing India's export-import trade performance across product categories and trading partners.
## What this project does
- Cleans and structures 5 years (2020-2024) of trade data across 8 product categories and 10 trading partner countries
- Calculates total exports, total imports, trade balance, and top trading partner per category using
**SUMIFS** **INDEX-
MATCH**, and
**MAXIFS**
- Flags categories running a trade deficit vs. surplus
- Visualizes results in a Power BI-style dashboard (bar charts comparing exports/imports and trade balance by category)
## Files
- 'India_Trade_
_Analysis.XIsx* - full workbook:
- 'Trade Data' - raw dataset
'Analysis' — formula-driven summary table
- 'Dashboard' - charts
## Key insight
3 of 8 product categories (Pharmaceuticals, Petroleum Products, Gems & Jewellery) show a consistent trade deficit
— a starting point for a sourcing-diversification recommendation.
## Note on data
This uses an illustrative sample dataset built to mirror the structure and scale of India's public trade statistics (Ministry of Commerce & Industry / DGFT trade data portal), for portfolio demonstration purposes. It is not live government data.
